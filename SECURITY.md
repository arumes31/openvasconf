# Security policy

Please report suspected vulnerabilities through [GitHub's private vulnerability
reporting form](https://github.com/arumes31/openvasconf/security/advisories/new).
Do not open a public issue containing credentials, exploit details, customer
addresses, scanner output, or Greenbone connection data.

We will acknowledge a report within 7 days and coordinate disclosure after a fix
is available. Security fixes are provided for the latest release and the current
`main` branch.

Container consumers should deploy by immutable digest and verify the GitHub
attestation and Cosign signature described in the README.
